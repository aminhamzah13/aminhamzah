Sample work

How I document tests and defects, from Kopra.

TC-KOP-014Passed

Interbank transfer via bulk file upload

Given
A maker uploads a 500-row CSV with 3 invalid account numbers.
When
The file is validated and submitted for approval.
Then
3 rows are rejected with a reason, 497 are queued, and the total amount matches.
BUG-KOP-221Critical, fixed

Payroll debited twice when approval is retried after a timeout

Found
SIT, before launch.
Steps
Approve a payroll batch, force a gateway timeout, retry the approval.
Fix
Idempotency check on the approval request, verified in regression.
